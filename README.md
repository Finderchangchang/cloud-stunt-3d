# 云上叠罗汉

一个 3D 小短片：鹈鹕骑着自行车，骑在孙悟空开的双翼机机翼上；鹈鹕的翅膀上托着骑北极熊的秦始皇，同时喊出糖果题的答案 21。

单个 HTML 文件，WebGL 实时渲染，不依赖外部库。打开 `index.html` 即可观看。

- 拖动画面：自由视角；滚轮：缩放
- 空格：暂停；F：切换视角；数字键 1–7：跳到对应镜头
## 黄昏版

用 three.js 重做的一版，黄昏逆光，43 秒：https://finderchangchang.github.io/cloud-stunt-3d/golden/
